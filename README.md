# Newton–Raphson — tiga studi kasus

Python 3; program utama tidak memerlukan paket tambahan.

1. Ekstrak ZIP.
2. Buka terminal pada folder source_code.
3. Jalankan: python newton_raphson.py
4. Jalankan pengujian: python uji_kasus.py
Windows juga dapat memakai perintah py.

Kasus: sisi persegi luas 50 m², rusuk kubus volume 10 m³,
dan waktu benda mencapai tanah dari h(t)=20+5t-5t².
Data adalah ilustrasi pembelajaran.

Toleransi perubahan dan residu 1e-8. Newton: 3, 4, 5 iterasi.
Biseksi: 29 iterasi per kasus. Kriteria langkah Newton dan lebar
interval biseksi berbeda; lihat laporan untuk interpretasinya.

hasil_eksperimen.json dan lingkungan_uji.json adalah catatan hasil
pengujian yang disertakan. Program terminal tidak menimpa berkas ini.
Tidak ada repositori publik yang dibuat.
